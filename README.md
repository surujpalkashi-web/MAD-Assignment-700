Java Android application that suggests recipes based strictly on leftover ingredients to reduce food waste.

## Database
SQLite (local) using SQLiteOpenHelper + DataSource pattern.

## Theme
Professional blue colour scheme.

## Package
`com.kashi402307064.smartpantrymanager`

## How to use these files
1. Open your Android Studio project
2. Create package: `com.kashi402307064.smartpantrymanager.db`
3. Copy files from `db/` into that package
4. Replace/add files from `model/`
5. Replace `app/build.gradle.kts` with the one in this ZIP
6. Replace `res/values/colors.xml` and `themes.xml`
7. Delete `google-services.json` if present
8. Sync Gradle
